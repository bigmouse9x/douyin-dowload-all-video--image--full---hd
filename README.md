# douyin-dowload-all-video--image--full---hd
This is a utility that helps you download videos from Douyin and TikTok to use as reference materials for your studies.
Download and extract the file, then open the utilities section, enable developer mode, and select "Load extracted utility".
Usage steps 
Step 1: Open the creator channel page for reference.(Tip: You should load the entire creator channel page to ensure the videos load correctly.)
Step 2: Open the utility and select: save douyin tab
Step 3: Select: Open dasboard

Step 4: Select : Scan media

Wait a moment for the extension to scan the media.
After the scan is complete, select the media you want to download, or choose the videos you want to download.
