# 🚀 Douyin & TikTok Pro Downloader (V26)

A powerful, smart, and background-running Chrome Extension designed to extract and bulk-download high-quality media (Videos, Images, Audio) from Douyin and TikTok. 

Equipped with a **Global Side Panel** and a **Smart Memory System**, this tool allows you to scrape thousands of posts without downloading duplicates or getting your IP blocked.

---

## ✨ Key Features
* **Global Side Panel:** Runs seamlessly in the background. You can switch tabs or work on other things while the extension extracts data.
* **Smart Batch Memory:** Automatically remembers which videos have been downloaded or exported. In the next batch, it automatically skips the old ones and only processes new media.
* **No Watermark:** Extracts the purest, highest-quality HD videos and images directly from the API.
* **Multi-Format Extraction:** Capable of scraping MP4 (Videos), JPG (Photo Carousels), and MP3 (Background Music) simultaneously.
* **Raw Link Export:** Instantly scrape thousands of raw profile links with a single click.

---

## 🛠️ Installation Guide (Developer Mode)

Since this extension is packed with powerful scraping tools, you can install it manually via Chrome's Developer Mode:

1. Download the source code and extract it to a folder (e.g., `Douyin_TikTok_Pro_V26`).
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Turn on **Developer mode** (toggle switch in the top right corner).
4. Click **Load unpacked** and select the folder you created in Step 1.
5. Pin the extension to your toolbar for quick access!

> **⚠️ CRITICAL CHROME SETTING:** > To prevent Chrome from asking you to save every single file during batch downloads, you MUST go to **Chrome Settings > Downloads** and **Turn OFF** the option: *"Ask where to save each file before downloading"*.

## 📖 How to Use

### Part 1: 🇨🇳 Downloading from Douyin (Batch HD Download)
1. **Navigate to a Profile:** Open any Douyin user profile page and scroll down to load as many videos as you want.
2. **Save Tab:** Click the extension icon to open the Side Panel. Under the Douyin section, click **"Bước 1: Save Douyin Tab"** (This clears the old memory and registers the current page).
3. **Open Dashboard:** Click **"Bước 2: Mở bảng Dashboard"**. A new tab will open, displaying all the media found on that profile.
4. **Batch Selection:** In the Dashboard, enter your desired batch size (e.g., `200`) and click **"Chọn [200] file chưa tải tiếp theo"**.
5. **Download:** Click **"Download Selected"**. The downloaded media will fade out. Next time you click select, it will smartly skip these and pick the next 200 files!

### Part 2: 🌍 Downloading from TikTok (Single & Batch TXT Export)
*Note: TikTok extraction exports `.txt` files containing direct media links, which you can then import into Internet Download Manager (IDM) or any bulk downloader.*

#### 🎯 Single Media Download
1. Open a specific TikTok video or photo slide.
2. Open the extension Side Panel (it auto-detects the link).
3. Click **"Get TikTok Links"**.
4. Choose to download the No-Watermark Video, Audio, or Images.

#### 🚀 Batch Export for IDM (Smart Memory)
1. Go to a TikTok user profile and scroll down to load videos.
2. In the Side Panel's TikTok section, locate **"Mục 3: Xuất TXT KHÔNG LOGO"**.
3. Enter your **Batch Size** (e.g., `100`).
4. Click **"🚀 LẤY CẢ 3"** (Extract All). The extension will run in the background, decode the API, and download 3 separate `.txt` files (Video, Image, Music) for the first 100 posts.
5. Scroll down the webpage to load more videos, then click **"🚀 LẤY CẢ 3"** again. The tool will automatically ignore the first 100 posts and extract the next batch!

#### 🔗 Export Raw Links
Need the original post links instead of direct media files? Go to **Mục 4**, enter your batch size, and click **"🔗 Lấy toàn bộ Link Gốc"**.
